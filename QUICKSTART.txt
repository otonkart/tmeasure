TMeasure v1.1.3 - Quick Start Guide

1. Installation

In Blender, go to Edit > Preferences > Get Extensions.

Click the drop-down menu in the top right and select Install from Disk.

Select the tmeasure.zip file and install.

Note: Make sure blender_manifest.toml and tmeasure.py are inside the zip file.

2. Where to Find the Add-on

Open the 3D Viewport.

Press N to open the Sidebar.

Click on the Measure tab. You will see the tmeasure panel.

3. Core Features & Usage

Object Dimensions & Scale Check:
Select any mesh object. The panel instantly displays its bounding box dimensions (X, Y, Z). If the object's scale is not applied (1.0), a red warning box will appear. Click the Apply Scale button to fix it non-destructively.

Smart Calculation (Edge Length / Face Area):
TMeasure automatically adapts to your active selection mode.

Enter Edit Mode (Tab).

If you are in Edge Select Mode (2), the tool calculates the total Length of the selected edges.

If you are in Face Select Mode (3), the tool calculates the total Area of the selected faces.

Select the desired edges or faces.

Click the Calculate button. The result will display the correct metric (area is indicated by ²) based on your active mode.

Unit System:
Use the Unit dropdown to switch between Meters (m), Centimeters (cm), Millimeters (mm), Feet (ft), and Inches (in) on the fly. All existing values in the panel will update automatically.

Clipboard & History:

Copy: Click the copy icon next to your "Last Total" to copy the exact value to your clipboard.

History: The panel saves your last 5 measurements, displaying the Object Name, Value, and Unit for easy tracking. Click the trash icon to clear the history.
